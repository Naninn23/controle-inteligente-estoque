# Estoque Brasil

Crie o Estoque Fácil: um mini ERP web profissional, responsivo e em português (BR) para gestão de estoque de pequenas e médias empresas. Implemente como aplicação funcional, não protótipo: habilite backend persistente e autenticação, banco relacional multiempresa com RLS, regras transacionais de estoque e trilha de auditoria. Priorize o núcleo completo: login, dashboard com KPIs e gráficos, produtos/SKU único, categorias/subcategorias, fornecedores, posição de estoque, entradas e saídas multi-item, movimentações imutáveis com saldo anterior/posterior e custo médio ponderado, bloqueio padrão de estoque negativo, inventário com ajustes, relatórios, usuários/perfis, alertas, auditoria e configurações. Inclua dados fictícios ricos para demonstração, UX SaaS/ERP limpa, menu lateral recolhível e responsividade. Garanta persistência e que as telas estejam conectadas às regras de negócio.
